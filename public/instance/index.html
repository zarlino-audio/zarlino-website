Zarlino Instance Setup

Turns any Windows 10/11 machine into a full Zarlino runtime instance - task daemon + WhatsApp bridge host, with auto-start and end-to-end verification. No SDKs, no admin needed for the core path.

⤓ Download ZarlinoInstanceSetup.exe (7 KB)
  1. Run ZarlinoInstanceSetup.exe on the machine.
  2. It fetches the current provisioner from this site (never stale) and checks git/node.
  3. You type the two secrets when prompted - nothing is ever printed or sent anywhere else.
  4. It clones the OS repo, installs dependencies, sets up the task daemon and the WhatsApp bridge (auto-start + restart-loop).
  5. It registers the machine in the org registry and verifies the daemon + bridge heartbeats end-to-end.

Preview without changing anything: ZarlinoInstanceSetup.exe -CheckOnly.
Custom instance id: ZarlinoInstanceSetup.exe -AgentId ws_studio_02 -CloneWorkspace.
Move the WhatsApp session without a QR scan: -BridgeSessionZip session.zip. Daemon only: -NoBridge. Non-interactive: -Yes.

Provisioner source (same file the EXE downloads): zarlino-instance-setup.ps1

Verify the instance afterwards: os.zarlinoaudio.com - org registry shows the new instance as ACTIVE, and the doctor check whatsapp.bridge goes OK.

Once verified, retire the old host with scripts\retire-this-machine.ps1 - full runbook: docs/INSTANCE_AND_RETIREMENT.md in the OS repo.
